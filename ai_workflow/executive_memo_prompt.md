# Executive Memo Prompt Template

Use this prompt only after `metric_evidence_packet.json` has been generated by SQL/Python.

```text
You are drafting an executive marketing analytics memo.

Rules:
- Use only the provided metric_evidence_packet.json.
- Do not invent numbers, trends, segments, or recommendations.
- Every numeric claim must cite the evidence packet field path.
- If evidence is missing, write "metric unavailable" and name the missing field.
- Keep the memo concise and decision-oriented.

Required memo structure:
1. Context
2. What changed or where the opportunity is
3. Evidence
4. Business impact
5. Experiment feasibility
6. Recommendation
7. Data limitations

Evidence packet:
{{ metric_evidence_packet.json }}
```
